# 几何重建网表与硬件文档

## 1. 提取流程

```bash
<managed-python> -m venv <venv-dir>
<venv-dir>/Scripts/pip.exe install pymupdf
<venv-python> scripts/extract_schematic.py <input.pdf> <outdir>
```

产出：`words.json`（逐页文字 token + bbox）、`wires.json`（轴对齐线段 + 元件体框）、`netlist.json`（`{net_id: {labels, nodes}}`）、`pageN.png`（200 dpi 整页）。

`word` 记录布局：`[x0, y0, x1, y1, text, block_no, line_no, word_no]`，单位为 PDF 点，原点左上，y 向下增长。

## 2. 算法要点与容差

| 常量 | 值 | 作用 |
|---|---|---|
| `SNAP_Q` | 2.0 pt | 端点栅格吸附量子 |
| `TOL` | 2.6 pt | 端点合并容差 |
| `LABEL_TOL` | 9.0 pt | 标签中心到 net 节点的最大挂接距离 |
| `PAGEBOX_MIN` / `_H` | 25 / 18 pt | 判定元件体的最小宽 / 高 |

步骤：

1. `collect_geometry()` 遍历 `page.get_drawings()`：`'l'` → 线段，`'re'` → 矩形，`'qu'` → 拆成 4 条边。
2. 只保留轴对齐线段（`|Δx| < 0.6` 或 `|Δy| < 0.6`），其余视为器件图形丢弃。
3. `body_boxes()` 排除整页图框（宽 > 700 且高 > 500）及其同原点副本，其余按宽高阈值判为元件体。
4. 丢弃完全落在某元件体内（pad 1.5 pt）的线段 —— **这一步不做就会熔掉整颗 IC**。
5. 线段端点经 `snap()` 后 union；再两两合并 `TOL` 内的相邻端点。
6. T 型节点：若某节点落在另一条线段的**内部**（正交方向距离 ≤ `TOL`，沿轴方向在两端点之间）则 union。
7. 文字 token 按切比雪夫距离挂到最近的 net，超出 `LABEL_TOL` 不挂。

## 3. Altium token 切分

- `CO<refdes>` — 器件标注，无歧义，用来建立**已知 refdes 集合**。
- `PI<refdes><pin>` — 引脚标注；`PIU11010` = `U11` 的 pin 10，`PIU1032` = `U1` 的 pin 32。
  切分规则：在已知 refdes 中找"是该 token 前缀、且余项为纯数字"的那个。
- `NL<name>` — Altium 自动生成的网络别名（如 `NLPA0` ≡ `PA0`），文档里写明等价关系，避免固件作者困惑。
- 交叉校验时必须剥掉 `PI*` / `CO*`，剩下的才是真实 net 名。

## 4. 重建结果自检

| 检查项 | 期望 | 失败含义 |
|---|---|---|
| 每页 net 数 | 几十个量级，不是 1~5 | 元件体框漏进了导线集合 |
| 最大 net 的标签数 | < ~40 | 某 MCU/IC 外框未被排除 |
| 每个电源轨 | 在其被使用的页面上至少出现一次 | 标签未挂上，需提高 `LABEL_TOL` |
| 地网络 | 存在且节点数多 | 同上 |
| 标签最丰富的 net | 是总线 / 电源轨 | — |
| 只带 2~4 个标签的 net | 是应在裁剪图里读到的信号网 | 有 net 没被读到 |

真实 net 名形如 `SPI_SCK`、`+3.3`、`PWM1`、`ADC_IN+`。

## 5. 硬件文档结构（读者是固件开发者）

- 系统概览 + 电源树框图（ASCII 即可）
- MCU 引脚分配表：脚号 / port / net 名 / 功能
- 每个外设一节，各带引脚表
- 外部连接：连接器、调试口、测试点
- 电源轨表：来源器件、拓扑、电压、负载
- 固件注意事项：共用总线、反相 / 低有效逻辑、时序约束、未使用引脚
- 显式标出每一个 NC 引脚

## 6. 文档里必须点名的硬件陷阱

- **共用总线**：两个外设共用 SPI SCLK/MISO/MOSI 但各自独立片选 → 固件必须串行访问。
- **反相逻辑**：信号经施密特反相器后，MCU 读到的是物理传感器状态的**反相**。
- **低有效使能**：`nSLEEP`、`nFAULT`、`TCUTx_EN`，务必写清极性。
- **差分对交叉**：核对哪个输入落在 `IN+` / `IN−`；导出原理图常与符号标注顺序相反。
- **串联端接电阻**：MCU 到外设之间的 `33Ω` 排阻是**串联**，不是上拉/下拉，别误读成偏置网络。
- **有源 vs 无源晶振**：带 `VCC`/`GND`/`OE` 的四脚 `Y` 符号是**有源**振荡器，不需要负载电容配置。
- **NC 标记**：引脚上的 X 表示真正未连接、不可扩展，逐个列出。
