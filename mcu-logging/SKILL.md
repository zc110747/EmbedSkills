# MCU 全局可控日志系统

把散落的裸 `printf` 收敛成一个可一键关闭、非阻塞、任意上下文安全的日志原语。

## 何时用

- 工程里散落 `printf("...")`，想统一成单一日志原语。
- 发布版要关掉全部日志以省 FLASH/RAM/串口带宽，调试版全开。
- 出现「日志时有时无 / 串口卡死」：多为 `printf` 走 newlib `_write` 重入串口发送锁，或裸打印在堆损坏、调度器未启动时崩溃。
- 需要在启动早期、任务内、堆损坏时都能安全打印。
- 无 RTOS 工程要非阻塞串口日志，且不想引入互斥量。

## 核心知识点

1. **三层结构，绝不重入串口发送锁**：日志宏 → 唯一 sink 函数 → `vsnprintf` 进栈缓冲 → 按显式长度写入 TX 环。绕开 newlib `printf`/`_write` 的重入锁。
2. **编译期零成本关闭**：开关为 0 时日志宏展开为空语句，实现函数体也早返回——不占 FLASH/栈，不产生任何串口流量。开关默认值用 `#ifndef` 兜底，便于构建系统覆盖。
3. **栈缓冲格式化**：固定大小栈缓冲，不分配堆；按 `vsnprintf` 返回值截断到缓冲上限，返回 `<0` 直接返回。启动早期与堆损坏时仍可用。
4. **双 TX 路径按调度器状态切换**：调度器未运行或串口未就绪 → 阻塞轮询发送，绝不丢字节；调度器运行后 → 取互斥量后写入 TX 环，由 TXE 中断搬出。
5. **懒互斥量**：串口初始化常早于堆定义，互斥量不能在 init 里创建，否则落在未定义的堆上；改为首次写入时在临界区内惰性创建。
6. **裸机变体：TX 中断驱动环形缓冲**，临界区用「关闭 TXE 中断」而非互斥量——TX 环索引被线程与 ISR 共享，只有禁中断能真正互斥。改索引期间禁中断，首字节 prime 进数据寄存器必须在重开中断之前。
7. **单文件日志模块范式**：日志宏 + 串口 + 标准输出重定向收进一个源文件，让 GCC(newlib) 与 ARMCLANG(MDK) 共用同一份日志实现，避免两套割裂的垫片。

## 判据与反模式

- 关闭是否真生效：TX 环写指针恒为 0、busy 恒为 0（一个字节都没进环），而不只是「串口没输出」。
- 双构建（开关 × Debug/Release）在 `-Wall -Wextra` 下 0 warning；关日志可省数 KB FLASH，验收报差值。
- 中断上下文禁止调日志宏：内部可能取互斥量，只调串口直写或 TX 中断服务函数。
- 二进制 / 含 `0x00` 的数据不要走 `%s` 格式化路径，串口直写并自行加编译期开关包裹。
- TX 环容量过小（如 512）在 115200 下连续打印即爆；批量 dump 必须限流，否则静默丢掉其它任务日志。
- 不用 `sed -i` 或整体 `"\n".join` 重写 CRLF 源文件——行尾会变 `\r\r\n`，破坏 `#if` 续行。
- 删工具链垫片前记住：编译链接能过 ≠ 运行安全，半主机类垫片被删往往延迟暴露为停机。
