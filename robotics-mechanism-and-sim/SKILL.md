# robotics-mechanism-and-sim · 机构真值与仿真判据

## 何时用

- 改机构参数前要先量：真值从哪来、能不能信、怎么证可复现。
- 机构改真值后的连锁影响与校验顺序。
- 仿真（MJCF/物理引擎）没复现真机行为、残差多大算对、判据是不是恒绿。

## 核心知识点

| 主题 | 结论 |
|---|---|
| 真值唯一 | 尺寸/限位/标定/耦合只存一份；禁止在测试、固件、前端各留一份常数 |
| 测量可复现 | ROI / 阈值 / 骨架模型必须跨 ≥2 批验证；单批最优 = 过拟合 |
| 区间搜索 | 最优落在区间端点附近 ⇒ 那是区间人为截断，不是测量结果 |
| 参考实现 | 读 STEP/URDF 等复杂格式用官方参考实现；自研解析器的否定性结论必须先复核 |
| CAD 边界 | 可由实体圆柱面反解**关节轴**；`length` 不可由 STEP 反推（STEP 姿态 ≠ 零点位）⇒ 只能标尺实拍 |
| 关节结构 | 两轴严格平行 ⇒ 平行四连杆的结构性签名，比经验拟合强 |
| 绝对角/局部角 | 耦合关节的合法域是"斜"的，轴对齐 `range` 无法表达；限位真值只在真值文件 |
| 物理量真值 | 取官方模型文件，不复制数值；`--check` 读引擎生效值，不读 XML 文本 |
| URDF/MJCF | 两份官方描述常数值不一致，按"引擎真正执行的那份"裁决；由此产生的残差不是 bug |
| 判据有效性 | "跑全绿"什么都不能说明；须跨批（换种子）+ 注入（扫翻转点）证明会红 |
| 容差 | 按对象登记 + 写明理由 + 未登记一律 `raise`；给"够大"的缺省 = 藏起精度来源 |
| 物理稳态 | 重力 + 有限 PD ⇒ 停在力矩平衡处；判据是"它在不在动"，不是"差多少" |

## 判据与反模式

- 三态 `ok` / `reject` / `undecidable`；**"判不了" ≠ "不合格"**，判不了时禁止输出像结论的数字。
- 禁止用"开机静态偏差"做自校准（快照取在松弛期，不可复现）。
- 固定 seed 跑很多次 ≠ 跨批，跨批必须换种子。
- 物理稳态偏差按链路登记容差，不放宽全局阈值，更不改物理模型凑判据。
- 改真值顺序：重生成产物 → 重冻结基线 → 重采黄金数据 → 修写死旧值的断言 → 同步文档。
- 方向类标定会翻转"钳位端"：改 `reverse` 后所有越界用例要逐个重算期望值（方向反了照样绿）。
- 冻结基线判据是**语义核心哈希**：改外观放行，改运动学/物理量报错；`tcp` 在语义核心里，别顺手改。
- 已放弃路线：CAD→URDF 直接接入、从 STEP 反推 `length`、自研 STEP/URDF 解析器、用 mesh bbox 当连杆长。
