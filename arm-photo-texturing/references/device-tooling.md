# 2.6 真机指令工具：五条安全设计（写任何一个都别省）

真机调试需要一个"只动一个关节看一眼"的脚本入口，**不能拿验收脚本当摇杆**
（验收脚本的假设是有序全流程，不适合手动插入单步）。

1. **限位来自设备握手，不硬编码**（本项目取自 `hello`）；**发送前本地校验**，
   越限直接拒绝并打印合法范围。
2. **只有 `device === 'serial'` 才允许发送**。⚠️ 实测本项目 `hello` 里**没有 `connected` 字段**
   （协议文档写了，属**文档漂移**）⇒ 判据只能看 `device`。**握手后 dump 一次原始报文再写判据。**
3. **"保持不变"的关节必须取最新一次 `joint_state`，不能取 `homePose`。**
   ⚠️ 实测 `hello` 与 `joint_state` **同时到达、`hello` 在前** ⇒ 若在 `hello` 分支就发指令，
   未指定的关节会 fallback 到 `homePose` —— 那不是"保持"，是**把臂拉回 home**。
   **发送点必须挪到收齐 `joint_state` 之后。**
4. **要 `--home`**（见上，实验可比性）。
5. **必须显式声明"没有位置反馈"**：`--settle` 只是"给舵机时间走完"，
   **不是"已确认到位"**。MG90S 一类舵机无位置回读，`OK SET` / `STATUS` 全都在说
   "我打算去哪"，**没有一条能证明它实际在哪**。唯一的外部地面真值是**相机**。

# 2.7 ★★★ 纯几何走不通时：**致动并观察（motion-diff）**

**当"从模型推位置"失效时，让系统自己动一下，差分就是答案。**

做法：**动一个关节 → 拍前后两帧 → 做差分**。
差分区域 = **该关节及其下游零件**。
完全不依赖"相机在哪""板面朝向""正交还是透视"等任何假设 ——
因为对应关系是**测出来的**，不是**推出来的**。

```
基准帧（HOME）→ 只改 shoulder → 拍帧 → 差分 ⇒ 大臂 + 其下游全部
基准帧（HOME）→ 只改 elbow    → 拍帧 → 差分 ⇒ 小臂 + 其下游
基准帧（HOME）→ 只改 base     → 拍帧 → 差分 ⇒ 底座以上全部
```

**怎么用它做归属判定**（这是纯几何做不到的事）：

| 想要的部件 | 判据 |
|---|---|
| **大臂** | 随 `shoulder` 变 **且** 不随 `elbow` 变 |
| **小臂 / 夹爪** | 随 `elbow` 变 |
| **立柱 / 底座 / 静止件** | 三个动作都不变 |

实测（本机）：`shoulder` / `elbow` / `base` 各改变画面 **19.87% / 14.25% / 16.08%** 的像素。

**★ 顺带解决一个认知陷阱：「无位置回读」≠「没动作」。**
舵机没有位置反馈，只说明**不能证明"到位"**，**不等于"没动"**。
差分给了正面证据 —— 这比"看串口回执"可靠得多（回执说的只是"我打算去哪"）。

**⚠️ 但它给不出干净的单板四角。**
肩座、平行连杆、线缆、阴影与目标板连成一片 ⇒ PCA 外接四边形得到的是**整块区域**
（实测 bbox 395×445 px，远大于单块板）。
⇒ **motion-diff 负责「归属判定 + 粗定位」，精确四角仍需人工标 + 目视复核。**

**实现要点**：
- 每次动作之间**必须回基准位**（回零），否则状态跨实验累积，差分混入上一次的残留。
- 差分前**腐蚀**一次（`MinFilter(5)`）去散斑：背景/线缆在帧间会闪烁，
  不腐蚀会得到满屏噪点、bbox 直接变成整帧。
- 限 ROI：只关心机械臂所在区域，别让桌面/背景参与。
- 差分图用三色画最易读：**灰 = 两帧都暗（未动）· 红 = 只在基准帧暗（原位置）· 绿 = 只在动作后暗（新位置）**。
