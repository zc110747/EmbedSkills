# 布局常量与字体标定

## 1. 布局常量表怎么组织

**一个集中文件**（如主题/度量模块）承载全部数值。散落在各控件里的魔数必然失控。

```text
// ── 窗口 ──
WindowWidth / WindowHeight
// ── 表头 / 页脚分隔线 ──
HeaderLineY / FooterLineY / SeparatorThickness
// ── 各区域元素：X/Y/W/H ──
// ── 行布局：行距、首行中心、起始列 X ──
// ── 配色：Background / TextPrimary / TextMuted / Accent / Link / Separator ──
// ── 字号：Title / Subtitle / Body / Small / Footer ──
```

**每个常量带出处注释**：

```csharp
/// <summary>数值字段下划线距行中心的纵向偏移。
/// 参考图给 8，但那是原件自绘文本的墨迹底边；本工程数值放在真实输入框里由系统垂直居中，
/// 墨迹底边只到行中心下方约 5.5px（实测右栏第1行墨迹 y143..154，行中心 149），故标定为 6。</summary>
public const int FieldUnderlineOffset = 6;
```

> 注释里写清"**为什么是这个值**"和"**为什么不是参考值**"，比只写数值有价值得多。

## 2. 行布局的参数化

```text
行中心(i) = 首行中心 + i * 行距  (+ 额外分组空档)
```

- **行距**：从参考图相邻两行的墨迹中心差求出。
- **额外空档**：分组之间常有比行距更大的一段（如某两行之间多 17px），
  用 `ExtraGapIndex + ExtraGap` 表达，别塞进行距。
- **两栏并列**时：各自独立的起始列 X 与行距；控件横向范围要**互不重叠**
  （否则整行不透明底会遮挡另一栏）。
- **行控件的 bounds 不要跨栏**：否则一行会挡住邻栏。

## 3. 字体族选择

```text
优先用与原件同族的系统字体：
  枚举已安装字体（InstalledFontCollection）
  → 依次尝试候选名（含中文名与英文名，如 "Microsoft YaHei UI" / "微软雅黑"）
  → 命中即用
  → 全不命中回落到一个通用无衬线（不要崩）
```

**禁止**硬编码一个可能不存在的字体名 —— 换机器后会静默变默认字体，所有度量失效。

## 4. 字号标定流程（关键）

**现象**：字形宽度随字号**离散跳变**，因为渲染层把字号量化到整数物理像素高度
（`em_px = ceil(pt * dpi/72)`）。所以"14.0pt 宽 300、14.5pt 宽 320"完全可能，
**不能线性外推**。

```text
① 取参考图上某串文字的墨迹宽/高（物理像素）
② 用同族同字重的字体，在目标 dpi 下渲染同一串文字
③ 枚举若干候选字号（含小数），实测每个的墨迹宽/高
④ 选"最接近参考"的那个；把标定结果与参考值一起写进注释
```

**记录格式**（便于后人复核）：
```text
TitleSize = 14f     // 《艾尔登法环》 171x29 → 本工程 169x28
FooterSize = 10f    // 页脚说明 697x20 → 690x20（10.1pt 会跳到 726，故取 10）
```

## 5. 字重

- 原件常比 Regular 更粗、更高。
- 做法：先用 **同字族 Bold** 对齐墨迹高度，再微调字号。
- 若 Bold 过高、Regular 过矮，优先保"高度像"（人的第一印象是粗细与大小）。

## 6. 文字起点补偿

自绘文本控件（如 WinForms 的 Label）常有**内缩**（若干物理像素）。
若参考图的文字起点是 A，而本工程渲染后起点是 A + 内缩，则把控件 X 设为 `A - 内缩`。

**验证**：用像素统计量"墨迹左界"，与参考对比。

## 7. 窗口无边框

```text
① 关闭系统边框（如 FormBorderStyle.None）
② 自绘标题栏与窗口按钮
③ 实现拖动：在"标题区/封面区"的鼠标按下时
   发送 WM_NCLBUTTONDOWN + HTCAPTION 给窗口
④ 双缓冲：开启，避免自绘闪烁
⑤ 关闭 AutoScale（如果已手工做 DPI 缩放），避免双重缩放
```

## 8. 迭代纪律

- **改一版 → 构建 → 截图 → 对比**。不要攒一批改动。
- 每次对比留档（`before/after` 两张），便于"不满意时回退上一版"。
- 用户不满意时**先回退到上一个已确认版本**，再在此基础上调 —— 不要在坏版本上继续叠。

## 9. 反模式

- ❌ 常量散落在各控件里。
- ❌ 字号线性外推。
- ❌ 硬编码字体名。
- ❌ 行控件 bounds 跨栏。
- ❌ 分组空档塞进行距。
- ❌ 攒一批改动再一起看。
- ❌ 注释只写数值不写出处与"为什么不是参考值"。
