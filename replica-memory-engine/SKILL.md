# replica-memory-engine · 外部读写引擎

> `replica-` 系列第 2 步。**通用方法论，不绑定任何具体表格式**（Cheat Engine 表只是一类数据源）。
> 前一步：`replica-recon`；配套：`replica-mock-harness`（怎么在没有真目标时验证本引擎）。

## 何时用

- 要给某个功能"接线"：从符号 → 地址 → 读写值 / 装钩子。
- 签名扫描扫不到、命中可疑、或换版本后全失效。
- 指针链解不出地址、写到一半失败。
- 需要装/卸代码钩子，且必须保证能**完全还原**。

## 铁律

1. **写过 ≠ 生效。** 任何写入之后必须**回读校验**；只凭写函数返回成功不算数。
2. **通配符必须按字节数展开。** 一个占位 token 代表几个字节就必须展开成几个字节位置，
   折叠成一个是最阴的错误——**因为两边用同一套错规则时会互相印证、自检全绿**。
3. **扫描读取窗口必须钳制在可读范围内。** 为处理跨块重叠而多读的字节一旦越界，
   整块读取会失败；若调用方直接 `continue` 跳过整块，就会**一条都扫不到且不留日志**。
4. **代码钩子必须可完全还原。** 装载前记录原始字节，卸载后逐字节比对；
   覆盖长度必须落在**完整指令边界**上（由指令长度解码器算出，不照抄文档）。
5. **一次只上一个钩子**，真机确认不崩、效果可见，再上下一个。

## 引擎分层

```text
① 进程发现与附着  → 拿句柄 + 模块基址/大小
② 只读内存访问    → 逐页容错读、可读性查询、区域枚举
③ 签名扫描        → AOB（通配展开 + 锚点预筛 + 全量校验 + 钳制）
④ 符号解析        → 命中处取出 rip 相对操作数 ⇒ 静态变量地址
⑤ 指针链遍历      → 逐级解引用；末偏移只加不解引用
⑥ 字段读写        → 数值 / 位域；写后回读
⑦ 代码钩子        → 代码洞分配 + 跳板组装 + 装载/还原
```

## 核心知识点

| 主题 | 结论 |
|---|---|
| 符号语义 | 从符号拿到的常是**静态指针变量自身的地址**，读字段前必须**先解引用一次** |
| 符号解析 | `symAddr = hit + 指令长度 + ReadInt32(hit + 位移)`；指令长度与位移要对**同一指令**取值 |
| 指针链 | 逐级 `obj = ReadInt64(obj + off)`；**最后一个偏移只加不解引用**；任何一级为 0 即失败 |
| 链序 | 数据源里的偏移数组**可能是倒序**；逐项核对，别默认顺序 |
| 空指针含义 | 链中途为 0 ≠ 实现错，常是"还没进游戏/对象未加载"——要能区分并给出人话提示 |
| 通配展开 | `??`=1 字节；`????????`=4 字节（一个占位 token 含 8 个问号）；`*` 按语义单独规定 |
| 扫描预筛 | 取**最长连续固定片段**作锚点先筛，再对**全部固定字节**做全量校验，防假命中 |
| 版本常量 | 数据源里的版本占位（`sN` 之类）视作通配扫描；真实值另行提供或运行期反解 |
| 越界读 | 跨块重叠读取要**钳制到块尾**并逐页容错；失败不可静默跳过整块 |
| 写后回读 | 数值：写→读→比对；位域：按位读→改→写→按位读回比对 |
| 持续回填 | 有些值程序每帧改写 ⇒ 需要**周期性重写**（定时器），且关闭后必须停止重写 |
| 幂等还原 | 关闭功能时必须恢复到"开启前的原值"，而不是"某个默认值" |
| 代码洞 | 跳板需在目标指令 **±2GB** 内分配；分配位置由就近探测保证 |
| 两阶段组装 | 先分配拿到洞地址，再回填绝对立即数——避免调用方手算 rip 位移造成静默错位 |
| 指令边界 | 覆盖长度必须等于整数条指令长度之和；从指令中间切开 = 崩溃 |
| 指令解码范围 | 覆盖常见前缀/REX/双三字节操作码即可；遇到不支持（如 VEX/EVEX）**返回失败而不是猜** |

## 判据与反模式

- ❌ 扫描"命中即用"：不校验全量固定字节，短签名会假命中。
- ❌ 越界读失败后静默跳过：导致"零命中"且无日志 —— 需要显式计数与告警。
- ❌ 用写函数的返回值当"生效"证据。
- ❌ 直接 `Write` 未验证的立即数（应幂等换算：地址 + 指令长度）。
- ❌ 关闭功能时写死默认值而非还原原值。
- ❌ 一边开着持续回填一边断言"外部改动能保留"。
- ✅ 每步都给可观察证据：命中地址、命中处字节、覆盖长度、边界是否成立、回读值。
