# 唯一真值源：声明、解析与搬迁

## 一条铁律

尺寸 / 限位 / 标定 / 物理量**只能存一处**。任何"抄一份到别处方便用"都会制造第二份真值，
而它的漂移是**静默的**（改了 A 没改 B，没人知道该信哪个）。

## 真值的位置由所有者声明

真值住进"包"，路径**只在 manifest 里声明一次**，所有读者通过**唯一解析函数**取。

```yaml
# packages/<id>/manifest.yaml —— 只放身份 / 能力声明 / 指针
model:
  config:  packages/<pkg>/model/robot.yaml      # 运动学/标定/限位真值
  physics: packages/<pkg>/physics/physics.yaml  # 物理量真值（全 SI）
  urdf:    packages/<pkg>/urdf/<pkg>.urdf       # 生成物
  generated_by: packages/<pkg>/tools/gen_urdf.py
```

```python
# 唯一解析入口：新增路径字段必须登记，未登记即报错
declared_path(robot_id, "model.config")
```

★ **不能自己拼路径**：路径写错**不一定报错** —— 它可能解析到一个**仍然存在的**同名文件
（只是已属另一个机构）。这是"漏改的读者"最隐蔽的失败形态。

配套一条必需的反面测试：**故意构造坏 manifest**（缺字段 / 指向不存在 / 指向别的包），
断言它**报错并指出怎么修**。没有这条，登记表就是没人验的注释。

## 选择器只负责选择

```
config/robots.yaml                ← 只允许 id / name / config 三个字段（"有哪些、默认谁"）
config/robots/<id>/robot.yaml     ← 该机构的参数（唯一真值）
```

把参数"顺手"抄进选择器 = 制造第二份真值 ⇒ 禁止。
新增一台机构的正确姿势 = **丢一个配置文件 + 加一行选择器**，**不改代码**。

## 迁移的黄金判据

> **把这条断言 / 这份数据 / 这个工具放到另一台机构上，它还是"对的说法"吗？**

| | 例子 | 去处 |
|---|---|---|
| **成立**（只是数据不同） | 随机位形 FK 与引擎逐位一致；限位校验文案格式；几何↔运动学解耦 | **Core**（机制） |
| **不成立**（换台就是错话） | "零位竖直段 = 某三根连杆之和"；`elbow` 存绝对角 + 平行四边形耦合；被动腕派生出的反例窗口 | **包**（`packages/<id>/tests/`） |

"成立"的那类**仍然靠包的数据驱动** ⇒ Core 里不该出现任何型号**字面量**，
只该出现型号 **id 作为选择器**。

## 目录搬迁的三类静默失败（全部不报错，必查）

| # | 项 | 漏改后的表现 | 怎么查 |
|---|---|---|---|
| 1 | 选择器 / manifest 的**路径指针** | 解析到**仍然存在**的同名文件（不报错） | 逐条跑 `declared_path(...)` 断言 `exists=True` |
| 2 | "向上找标记"的**仓库根探测器** | 找不到根；若上层恰有同名目录则**静默错根** | 全仓 grep 标记字符串，把命中**数一遍** |
| 3 | **测试通道配置** | 包内测试**不再被执行**但**全绿**（0 失败 = 没跑） | `pytest --collect-only -q \| grep -c '^packages/'` 数**收集数** |

★ 第 3 类最阴，**必须实测收集数**才算验证过。配套要有一条**能红**的守卫
（读测试配置 + 断言覆盖了包目录）。

★ 仓库根探测的通用写法（替代一切 `parents[N]` / `Path(__file__).parent.parent`）：

```python
def _find_repo_root() -> Path:
    for parent in Path(__file__).resolve().parents:
        if (parent / "core").is_dir() and (parent / "packages").is_dir():  # ★ 标记
            return parent
    raise RuntimeError("找不到仓库根")
```

层数是**被搬迁改写的隐式契约**，写错时不报错、只是解析到另一个目录
（症状因此伪装成"文件丢了"）。

## 分阶段节奏（不可跳）

```
只读分析 → 契约建立 → 一次只搬/改一个子系统 → Build → Test → 验证 → 记录
                                                          ↑
                                            每一步交付一次**实测数据**
```

- **一次只动一个子系统**。同时改两处，红了不知道是谁。
- 每阶段产出一份阶段文档，固定结构：
  **一句话结论表 → 判据（什么随包、什么留 Core）→ 真 bug 清单 → 验收命令 → 未做清单**。
- **只读分析阶段不可跳**：先把"现状 + 目标 + 差异"写下来，再动手。搬迁类任务跳过这步必返工。

## 重命名目录报 `Permission denied` 时

**先判"路径被外部锁"而非 ACL** —— 判据是**同一父目录下的兄弟目录能否重命名**。
兄弟能改 ⇒ 不是 ACL。穷尽排查顺序：ACL 对比 → 逐文件 `FileShare.None` 试开 →
PEB 扫进程 cwd → 重解析点检查 → 换目标名 / 换 API（`Rename-Item` / `[Directory]::Move` / `mv`）
→ **都无效才判定为外部锁**。
