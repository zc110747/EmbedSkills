# replica-ui-fidelity · 界面 1:1 复刻

> `replica-` 系列第 3 步。核心：**把"看着像"变成"量出来"，并用像素证据复验。**

## 何时用

- 只有参考截图（原件不能运行 / 加密资源无法还原），要复刻布局。
- 界面改完要证明"和参考一致"，而不是"我觉得一样"。
- DPI 缩放、字体度量、控件遮挡这类"看起来对但细节错"的问题。

## 铁律

1. **所有几何/色值都要有出处。** 每个常量注明来自"哪张截图、哪个像素区间"。
   凭感觉给的数字必须在注释里标"待标定"。
2. **改完必须像素级复验**，不能只看截图顺眼。
3. **真实子窗口会盖住父控件绘制。** 横线/背景画在父控件上，被原生输入框整块遮住 =
   全图找不到该像素 —— 必须改为**同级子控件并置顶**。
4. **物理像素 ↔ 逻辑像素要分清。** 参考截图常是物理像素（含 DPI 缩放）；
   代码里的坐标若按逻辑像素写，运行期必须乘 `DeviceDpi / 96`。
5. **别用眼睛当判据。** 一条横线有没有显示，靠"统计该色值像素行"来判定。

## 工作流

| 步 | 目标 | 产出 |
|---|---|---|
| 1 | 取参考帧 | 原件截图（多张：整体 + 局部放大） |
| 2 | 定标尺 | 换算物理→逻辑像素；确定窗口客户区尺寸 |
| 3 | 量布局 | 每个元素的边界/间距/对齐，落成常量表 |
| 4 | 采样配色 | 背景/文字/强调色/分隔线的精确 RGB |
| 5 | 标定字体 | 用同族字体做宽度实测，选使墨迹宽最接近参考的字号 |
| 6 | 实现与迭代 | 按常量表落地；**改一版截一版** |
| 7 | 像素复验 | 统计目标色值像素行/列，与预期几何对齐 |

## 核心知识点

| 主题 | 结论 |
|---|---|
| 标尺 | 先确定截图的 DPI 缩放比；`逻辑 = 物理 / 缩放`。整个工程的坐标统一在**逻辑空间**写 |
| 布局常量 | 一个集中文件（主题/度量）承载全部数值，附实测出处注释；散落在各处必失控 |
| 字体族 | 优先用与原件同族的系统字体；用「已安装字体枚举」挑，不要硬编码一个可能不存在的名字 |
| 字号标定 | 字形宽度随字号**离散跳变**（GDI 量化到整数像素高度）；要逐个候选实测取最接近的，别线性外推 |
| 字重 | 原件往往比常规更粗；先用"同字族 Bold"对齐墨迹高度，再微调字号 |
| 行距 | 从相邻两行的墨迹中心差求出，不要用"感觉合适"的值 |
| 文字起点 | 自绘文本控件常有内缩（若干物理像素）；用负的 X 抵消，才与参考对齐 |
| 色值采样 | 在**平坦区域**取色（不要取到抗锯齿边缘）；多个位置取众数 |
| 强调色 | 常用于选中态/数值字段下划线；单独采一个，别复用文字色 |
| 子窗口遮挡 | 原生输入框/按钮是独立子窗口，覆盖父控件同区域绘制 → 要画的装饰必须是**同级子控件并 BringToFront** |
| 字段下划线 | 数值输入框下方的横线：用独立 Panel 子控件，位置由"数字墨迹底边"反推（约行中心下方 5~6 逻辑像素） |
| 边框窗口 | 无边框窗口要自己实现拖动（命中标题/封面区 → 模拟 `WM_NCLBUTTONDOWN`/`HTCAPTION`） |
| 语言/主题切换 | 文案与度量分离：文案查表，度量不动；切换后只重设 Text |

## 像素复验方法

**目标**：不看"像不像"，看"目标色值的像素分布是否与预期几何吻合"。

```text
① 整窗渲染（不被其它窗口遮挡也能截到）：
     Win32: PrintWindow(hwnd, hdc, PW_RENDERFULLCONTENT=0x2)
   ⚠️ 声明 DPI 感知，否则 GetWindowRect 返回虚拟化坐标，截图会被裁小
② 逐行统计「强调色」像素数与其连续长度 (run)
③ 断言：出现 N 条 run≈期望长度 的横线，且 x0 落在目标列区间
```

**典型输出**：
```text
y=155  run=90  x0=966   ← 第1个数值字段下划线
y=180  run=90  x0=981   ← 第2个
...
共 12 条，x0 全在 [966,1011]，行距 ~24.7 ≈ 行距常量
```

**判据**：条数 == 字段数；x0 落在预期列；行距 == 行距常量。
三者都对才算"可见且位置正确"。

## 反模式

- ❌ 把装饰画在父控件 `OnPaint` 里却盖着原生子窗口 —— 白画。
- ❌ 用"截图看着有"当可见性判据（小像素线人眼会漏）。
- ❌ 硬编码字体名导致换机器变默认字体、度量全崩。
- ❌ 用物理像素坐标直接写进代码、不做 DPI 缩放。
- ❌ 字号/间距靠"感觉"，不标定、不注明出处。
- ❌ 改了 UI 不重新截图对比，靠记忆判断"没变化"。
- ❌ 一次性改很多处再一起看：出问题不知道是哪处引起的 —— **改一版截一版**。
