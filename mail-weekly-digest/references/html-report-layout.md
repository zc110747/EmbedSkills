# 深色极简报告版式

用户已确认满意的版式，固定使用，不要自行改风格。

## CSS 变量

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0f1113` | 页面背景 |
| `--card` | `#171a1d` | 卡片背景 |
| `--card-2` | `#1c2024` | note 块背景 |
| `--line` | `#262b31` | 描边 |
| `--text` | `#e6e9ec` | 主文字（标题、数字） |
| `--text-2` | `#a8b0b8` | 正文 |
| `--text-3` | `#7c858f` | 元信息、标签 |

**禁止彩色点缀 / 状态色**：标签用 `--text-3` 文字 + `--line` 描边的小 chip，不要红黄绿。

## 结构顺序

1. **header** — 标题「邮件周报」+ 副标题（时间区间 / 账户 / 时区说明）
2. **`.stats` 四格数字卡** — 收件箱 / 已发送 / 未读 / 带附件
3. **「邮件明细」卡片列表** — 每张卡 = 主题（含可选 tag）+ 发件人 + 时间 + 2~3 句中文摘要 + 「已读·无附件」元信息行
4. **「分类统计」表格** — 来源 / 数量 / 性质
5. **`.note` 本周要点** — 把邮件归纳成 2~3 条**结论**，并标出「待你决策」的项（授权请求、报名截止之类）
6. **footer** — 生成时间 + 数据源

## 内容口径

- 明细卡按**重要性**排序：待决策 / 与技术栈相关 > 资讯 > 推广 > 广告；**不是纯时间序**。
- 摘要写成中文陈述句，不要照抄英文 snippet，也不要把 snippet 直接截断。
- 时间列显示本地时间（UTC +8 换算后），需与统计口径一致。
- 页脚与副标题里写明数据源与覆盖范围（未开通的账户要在此说明）。
