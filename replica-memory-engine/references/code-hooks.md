# 代码钩子（Code Hook）

> 用于**改逻辑**类功能（见 `replica-recon/references/behavior-boundary.md`）。
> 最高风险的部分：弄错一个字节就崩溃，且崩溃点常离错误点很远。

## 1. 结构

```text
目标指令处:  jmp <代码洞>          ← 覆盖 N 字节（必须是完整指令）
代码洞:      [可选副作用]
             原始被覆盖的指令（原样搬运）
             jmp <目标指令+N>       ← 回到原逻辑继续
```

## 2. 覆盖长度：必须由解码求出，不照抄文档

**为什么**：数据源给的覆盖长度可能**比真实指令边界短**（用 nop 补齐），
照抄会从指令中间切断 → 运行时崩溃。

```text
正确做法：
  len = 0
  while len < 声明的覆盖长度:
      n = DecodeLength(code + len)
      if n == 0: return false        // 不支持/非法，拒绝这个 hook
      len += n
  断言 len == 声明的覆盖长度        // 不等 ⇒ 边界不成立，告警
```

**指令长度解码器要覆盖什么**（够用即可）：
- 前缀：`F3/F2/66`（SSE）、段前缀、REX
- 单/双字节操作码、`0F 38/3A` 三字节操作码
- ModRM / SIB / 位移 / 立即数的长度规则
- **不支持 VEX/EVEX（AVX）时返回失败**，由调用方拒绝该 hook，**绝不猜**。

## 3. 代码洞分配：±2GB 约束

`jmp rel32` 的位移是有符号 32 位 ⇒ **目标必须在源指令 ±2GB 内**。

```text
分配策略：在目标指令地址附近逐步探测可分配区域
  （优先近地址；探测失败要明确报错，而不是随便分配一个远处地址）
```

**判据**：分配后立刻校验 `|洞地址 - 目标指令| < 2GB`，不满足就重试或失败。

## 4. 两阶段组装（推荐）

```text
问题：跳板里的标志变量、浮点常量常用「洞基址 + 偏移」寻址，
     而洞地址只有分配之后才知道。

两阶段：
  ① 先分配，拿到洞地址
  ② 回调调用方，用洞地址回填所有绝对立即数
  ③ 最后才写洞、改写目标指令

好处：调用方不需要手算 rip 相对位移 ⇒ 消除一整类静默错位。
```

## 5. 两种跳板布局

| 布局 | 语义 | 适用 |
|---|---|---|
| **Prepend** | 原指令整体前置，再叠加副作用 | 「原指令先执行、之后才需要我们的逻辑」 |
| **Flexible** | 自行重排原指令 | 「必须在我们改完寄存器之后，原指令才执行」 |

**Flexible 的典型场景**：某项功能要改 `edx`，而原指令是 `test edx,edx` ——
必须让 `test` 在写 `edx` **之后**跑，否则改了也白改。

## 6. 装载 / 还原核验

```text
装载：
  ① 读并保存原始字节（覆盖长度）
  ② 校验指令边界成立
  ③ 分配洞 + 组装跳板
  ④ 写洞
  ⑤ 改写目标指令为 jmp
  ⑥ 清指令缓存（如 FlushInstructionCache）
  ⑦ 回读目标处字节，断言 == 我们写的 jmp

卸载：
  ① 写回原始字节
  ② 回读，断言**逐字节等于**装载前保存的原值
  ③ 释放洞（可选）
```

**关键**：卸载后的判据是"**逐字节等于装载前**"，不是"大概恢复了"。
建议独立脚本在运行态核验**全部**站点解除后零残留（如 `OK=n BAD=0`）。

## 7. 一次只上一个

- 每一项都要单独验证：**不崩 + 效果可见**。
- 多个钩子同开时崩溃，很难定位是谁。
- 多项共用同一站点（如"飞行"与"锁定敌人"共用一处）时，要在跳板里按对象分流，
  并**显式记录**这种耦合关系。

## 8. 对象判定（倍率/免疫类的坑）

全局倍率如果**不做对象判定**，会对敌人同样生效。

```text
需要：比对本钩子拿到的对象身份 == 玩家身份
     （常见做法：入口保存寄存器，与"玩家实体指针"比对；
       或读对象基址处的类型/标记字段）
```

**必查**：该判定在**坐骑态 / 召唤物 / 多人场景**下是否仍正确；
未覆盖的情形要写进"未验证"清单。

## 9. 反模式

- ❌ 照抄文档覆盖长度。
- ❌ 用"洞地址 + 手算 rip 位移"而不做两阶段组装。
- ❌ 不支持的操作码"猜一个长度"。
- ❌ 随便分配到远处（超出 ±2GB）。
- ❌ 卸载后不逐字节核验。
- ❌ 多个钩子一起上。
- ❌ 全局倍率不做对象判定。
- ❌ 忘了清指令缓存。
