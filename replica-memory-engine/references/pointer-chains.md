# 符号解析与指针链

## 1. 符号解析语义（最容易搞错的一步）

从签名命中到"能用"的字段地址，标准链条：

```text
① 扫描命中指令地址 A
② 反汇编 A，取内存操作数 [rip + disp32]
③ symAddr = A + 指令长度 + ReadInt32(A + dispOffset)
④ 注意：symAddr 是「静态指针变量自身的地址」，不是对象地址
⑤ 读字段前：obj = ReadInt64(symAddr)，再沿指针链走
```

**陷阱**：把 `symAddr` 当对象地址直接加偏移 ⇒ 读到垃圾或崩溃。
**判据**：如果按对象地址解读得到"看起来像浮点的乱数 / 全部为 0"，先怀疑这一条。

**指令长度与位移要对同一指令取值**：`A + 7` 里的 7 与 `A + 3` 里的 3
都是**该指令自身**的布局，不要用别的指令的常量套。

## 2. 指针链遍历

```text
obj = ReadInt64(symAddr)              // 解引用一次，拿对象
for i in 0 .. offsets.Length-2:
    obj = ReadInt64(obj + offsets[i]) // 逐级解引用
field = obj + offsets[last]           // 末级：只加，不解引用
```

**三条铁律**：
1. **最后一个偏移只加不解引用**。解了就会把字段值当指针。
2. 任何一级读到 0 ⇒ 判定失败（不要继续算下去）。
3. **偏移数组可能是倒序**（数据源与直觉相反）；逐项核对。

## 3. 空指针的正确解读

链中途为 0 **不是实现 bug**，通常是运行期状态：
- 还没进入游戏 / 角色未加载 / 场景未初始化。

**要求**：
- 失败要返回"可读的原因"，而不是笼统的 `false`。
- 面向用户的提示要写人话（"未进入游戏"而非"链遍历失败"）。
- **不要**在拿不到地址时静默跳过 —— 要计数并汇总。

## 4. 数值读写

```text
写：
  WriteProcessMemory(field, value)
  ReadProcessMemory(field, out back)
  断言 back == value        ← 缺这一步，"写成功但没生效"查不出来

类型宽度：
  Byte / Int16 / Int32 / Int64 / Float / Double
  ⚠️ 宽度传错会"成功写入但值不对"（如把 int 当 byte 写）
```

## 5. 位域读写

一个字节里打包多个布尔开关时：

```text
读位：v = ReadByte(field); on = (v >> bit) & 1 != 0
写位：v = ReadByte(field); v = on ? (v | (1<<bit)) : (v & ~(1<<bit)); WriteByte(field, v)
校验：重新读回该位，断言等于目标
```

**必须"读-改-写"整字节**，不能只写该位所在的一个字节而丢掉同字节其它位。

**注意**：一个字段可能是"多组开关共用一个字节"，改 A 的位时不能把 B 的位清掉 —— 所以必须读-改-写。

## 6. 持续回填（Hold）

有些值程序**每帧重写** ⇒ 单次写入立刻被覆盖。

```text
开启：写入目标值 → 武装"回填"标记
驱动：定时器（如 200ms）周期性 Tick：
        if 武装: 重新写入目标值
关闭：解除武装 → 恢复开启前的原值
```

**验收判据必须三段式**（缺一段都会误判）：

| 阶段 | 操作 | 断言 |
|---|---|---|
| 武装 | 开启回填 | 值 == 目标值 |
| 篡改+驱动 | 外部写入别的值，驱动一次 Tick | 值**被回填**回目标值 |
| 关闭后篡改 | 关闭，再外部写入别的值，驱动 Tick | 值**不再被回填** |

**只测前两段是不够的**：第三段才能证明"真的解除了"，否则"关闭"可能根本没生效。

## 7. 还原语义

关闭功能时：
- ❌ 写"默认值"（如 0、100）—— 破坏了用户原本的状态。
- ✅ 写"**开启前的原值**"—— 开启时先读出来存好。

**例外**：如果原件本身就是"关闭即置 0"的语义，那要**按原件语义**实现并写进文档。

## 8. 反模式

- ❌ 把符号地址当对象地址。
- ❌ 末偏移解引用。
- ❌ 宽度传错（用 int 宽度写 byte 字段）。
- ❌ 只写单个位而丢弃同字节其它位。
- ❌ 关闭时写默认值而非还原原值。
- ❌ 单次写入不驱动就断言回填功能生效。
- ❌ 空指针时静默跳过不计数。
