# replica-runtime-takeover · 原版运行时接管

> `replica-` 系列：`recon` 摸清原件 → **本文接管运行时** → `ui-fidelity` 对齐像素 →
> `mock-harness` 离线验收。

复刻有两种做法：**重写规则**（迟早与原版行为分叉）和**接管运行时**（原版继续算，只换
输入与渲染）。本文只讲后者：把原版当黑盒进程/引擎，新层负责「拾取 → 投递原始输入」与
「读原版结果 → 表现」，规则零复制。

## 何时用

- 已有可运行的原版（JS 引擎、老程序、模拟器），要接 3D/新 UI，但**业务规则不能重写**。
- 接管后症状是：原版卡死、画面被切回旧界面、加载停在 entering、点了没反应或点到隔壁。
- 需要证明「原版一行没改」或「改动可机械还原」。

## 四条铁律

1. **规则零复制。** 新层里不得出现伤害公式、寻路、胜负判定、合法性校验。只允许两种代码：
   「拾取 → 投递输入」与「读结果 → 表现」。一旦复制，两边就会各自演化。
2. **可逆还原。** 对原件的改动必须能反算回原字节（改名、注入点偏移可枚举）。
   判据是**还原后与原文件逐字节一致**，不是"看起来没动业务逻辑"。
3. **状态只有一个源。** 当前处于哪个界面/阶段，只能读原版的执行位置；新层自己维护的
   并行状态机一旦与原版分叉，表现就是画面来回切、状态永久卡住。
4. **窗口由原版划定。** 不猜"现在该接管了"，而是监听原版某个调度函数的进入/返回，
   窗口外一律放行原文。接管函数必须幂等、可重入保护。

## 接管点清单

| 接管点 | 做法 | 失效症状 |
|---|---|---|
| 函数级拦截 | 构建期把目标函数名改成**全局唯一**的 `xxxOrig`，再注入同名 shim：`function xxx(...a){ notify(); return xxxOrig.apply(this,a) }`。模块作用域（IIFE/闭包）内的函数**无法从外部覆写**，改名 + 同名 shim 是唯一既不复制规则、又不动原逻辑的位置 | 直接给全局赋值无效；shim 里顺手改参数 ⇒ 行为分叉 |
| 输入桥 | 只投递原版本来就消费的**原始消息**（指针/按键码 + 原版画布坐标），不调用业务函数。坐标要换算回原版画布：格坐标 → 定点像素常是 `(格 - 视口原点) << 4`（Q4 定点，左移 4 位 = ×16） | 单位错：点了没反应 / 点到隔壁 / 选中错单位 |
| 等待注入 | 原版靠"等待输入"的定时器轮询推进时，在目标函数执行期间**临时替换等待器**注入一次消息，`finally` 必须还原 | 漏还原 ⇒ 之后所有输入永久失效（最像"原版挂了"的一种） |
| 视图接管 | 渲染层订阅原版阶段，只在 `game` 类阶段接管，`menu`/帮助/过场交还原版 2D；切回必须**先切视图再让原版消费**那一次输入 | 帮助页点一下就变成"确认选城" |
| 结果读取 | 战报/动画/战果取「调用前后快照的差」（纯减法）；视觉路径沿原版写下的**距离场/消耗场下降**生成折线（只读），不自己寻路 | 自己累加 ⇒ 与真实结算对不上；自己寻路 ⇒ 与原版落点不一致 |

## 判据

- **原版文件零改动**：`git diff` 为空、或改动仅限改名映射；还原脚本跑完 `sha256` 相同。
- **规则零复制的可检验形式**：在新层目录里 grep 业务常量/公式表，命中即违规；
  数值类判据（兵种掩码、颜色、系数）一律运行时从原版读，不落字面量。
- **断言口径与原版同源**：拿"队列人数"当"可操作单位数"会假失败——后者要经原版的
  过滤函数取。界面重开还可能落到另一座城，期望值必须取**界面当前**的那个 ID。
- **接管窗口的边界测试**：窗口内、窗口外各跑一遍；窗口外必须与未接管时行为一致。
- **可逆性测试进 CI**：还原 → 哈希比对 → 再接管，两步都过才算通过。

## 反模式

- ❌ 复制一份规则"顺手优化"——测试全绿，玩家能看出差异。
- ❌ 用自己维护的阶段变量驱动视图切换；原版在战斗里走"等消息"分支时会被误判成菜单。
- ❌ 切场景函数被抖动/轮询多触发一次就打断了状态机（加载永久停在 entering）：
  加"进入中/战斗中"保护，并把切换做成幂等。
- ❌ 替用户**补发按键**完成操作：多投的那一次会变成"确认"类语义（选城、下单）。
  需要吞掉紧随其后的 click（给一个 ~300 ms 的忽略窗）。
- ❌ 通过调试协议（CDP `setDeviceMetricsOverride` 等）改视口尺寸：会打断原版按启动尺寸
  算出的输入节奏（表现为"按了一串键仍停在开局"）。尺寸只能在**启动参数**里定。
- ❌ 俯视到 90° 时相机 `up` 与视线平行 ⇒ `lookAt` 退化、画面全黑/翻转；俯角 ≥89.5° 时
  显式换 `up`。
- ❌ 平移边界写常量：斜视下 frustum 大，看不出越界；俯视 fit 后一拖就整屏空白。
  边界要按 `max(0, 地图半幅 − 视野半幅)` 动态收敛。

## 验收顺序

1. 还原校验（哈希一致）→ 2. 原版单独跑通（未接管基线）→ 3. 接管后窗口外行为一致 →
4. 窗口内主链路真操作一次（真实点击/按键，不是直接调函数）→ 5. 像素/截图留证 →
6. 长跑看阶段是否漂移。
