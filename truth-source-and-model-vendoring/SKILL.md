# 唯一真值源与官方模型接入

处理同一份真值被多处实现、或多份官方描述各自表述导致的静默漂移；以及把上游官方模型引入自有工程并长期不漂移。

## 何时用

- 同一个量被两处独立实现，偏差达"一个物理量"的量级，**不报错、不崩溃**，判定却与直觉相反
- 接入上游的 URDF + MJCF + 网格，需与自有配置长期一致
- 运动学、限位、标定、物理量改动后，需要证明"没改坏"
- 建立多机构回归矩阵、Sim2Sim 验收

## 核心知识点

| 知识点 | 要点 |
|---|---|
| 唯一真值源 | 尺寸/限位/标定/物理量只存一处；路径由所有者在其 manifest 中**声明**，读者经**唯一解析函数**取；选择器只放 id / name / 指针，把参数抄进选择器 = 第二份真值。自己拼路径可能解析到一个仍然存在的同名文件而**不报错** |
| 冻结基线 | 判据是**语义核心哈希**（只含长度/限位/耦合/执行器标定）；整文件哈希会连改外观一起拦下，人便会习惯性 `--update` 抹红。真值冻结管输入，黄金数据（位姿/解/采样序列化）管输出，**分别冻结**——实现可能改坏而真值没动 |
| 多实现互证 | 至少两条独立实现互相对账并冻结残差。自实现 FK 去验自实现 IK，残差必然很小，属自证 |
| 两份官方描述 | URDF 与 MJCF **经常**数值不一致（帧朝向差 90°、rad 截断到 6 位）。裁决依据是**引擎真正执行哪一份** |
| 物理量从对象读 | 从已加载的模型对象（如 MjModel）读生效值，不解析 XML 文本——`<default class>` 会被逐实例覆盖，且有值根本不在文本里 |
| 容差登记制 | 容差按机构登记并写明理由，**未登记一律报错**，不给缺省值。悄悄给"够大"的缺省 = 为通过而放宽阈值的开端 |
| 能力门在调用点 | 缺某能力就声明为**不存在**（独立失败码），在**真正下发命令的那一层**挡。底层求解器被别的路径调用时会"成功返回"无意义结果 |
| 官方文件零修改 | 保留上游布局；偏离只走运行期引擎 API 覆盖并留记录 |

## 判据与反模式

- **诊断顺序**：先让两侧**同时打印**同一输入的结果（不靠读代码推演）→ 量偏差量级 → 判"常数 / 线性 / 系统性偏置 / 分支不同" → 定位"引擎真正执行的那一份" → grep 同类坑有无第二处。
- **修法是转发，不是"再算一遍这次算对"**：第二处实现必须消失。"为少 import 一个符号而自己重算"是错误经济学：多一条依赖可测可登记，多一份真值会腐烂。
- **只有会失败的检查才算约束**：每条纪律配一条**能红**的守卫，并**反向验证它真的会红**。永远为真的断言比没有检查更糟。
- **测试全绿 ≠ 覆盖到了**：路径或测试配置写错会让整批用例一条不跑而全绿 ⇒ 必须实测**收集数**，不能只看退出码。
- **两条独立证据链不能混读**：链路层全绿只证明"指令被送到并被接受"，不证明"物理到位"；无位置反馈时的回读是开环目标值。
- 反模式：改错字段而不消除第二处；用 `--update` 让测试变绿；用模型自声明的 id 反查选择器；把"键集合相等"当模型一致的判据；用欧拉角反解比对姿态（万向锁附近产出假失败）。
