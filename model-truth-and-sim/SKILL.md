# 唯一真值与仿真对等

同一份真值被多处实现、或多份官方描述各自表述，会产生**量级达一个物理量、却不报错**的漂移；
机构/物理参数改动后也可能"看起来没坏"。本篇只写判据：真值放哪、怎么证没漂、怎么证判据有牙齿。

## 何时用

- 同一个量在两处独立实现，偏差达"一个物理量"的量级，不崩溃、判定却与直觉相反。
- 接入上游模型（几何描述 + 网格 + 物理参数）后要长期不漂。
- 运动学 / 限位 / 标定 / 物理量改动后，需要证明"没改坏"。
- 仿真没复现真机行为：残差多大算对、判据是不是恒绿。

## 一、真值只有一份

| 判据 | 结论 |
|---|---|
| 单一来源 | 尺寸 / 限位 / 标定 / 物理量只存一处。禁止在固件、测试、前端各留一份常数 |
| 声明式路径 | 路径由**所有者**在其 manifest 里声明，读者经**唯一解析函数**取。自己拼路径可能命中一个仍存在的同名文件而**不报错** |
| 选择器契约 | 选择器只放 id / name / 指针；把参数抄进选择器 = 第二份真值 |
| 官方文件零修改 | 保留上游布局；偏离只走运行期引擎 API 覆盖并留记录 |
| 物理量取值 | 从**已加载的模型对象**读生效值，不解析 XML 文本——`<default class>` 会被逐实例覆盖，且有值根本不在文本里 |
| 两份官方描述 | 两份描述**经常**数值不一致（帧朝向差 90°、rad 截断到 6 位）。裁决依据是**引擎真正执行哪一份**；由此产生的残差不是 bug |

## 二、判据必须会红

| 判据 | 结论 |
|---|---|
| 冻结基线 | 判据用**语义核心哈希**（只含长度 / 限位 / 耦合 / 执行器标定）。整文件哈希会连改外观一起拦下，人就会习惯性 `--update` 抹红 |
| 输入输出分开冻结 | 真值冻结管**输入**，黄金数据（位姿 / 解 / 采样序列）管**输出**——实现可能改坏而真值没动 |
| 只有会失败的检查才算约束 | 每条纪律配一条**能红**的守卫，并**反向验证它真的会红**。永远为真的断言比没有检查更糟 |
| 三态判定 | `ok` / `reject` / `undecidable`；**"判不了" ≠ "不合格"**，判不了时禁止输出像结论的数字 |
| 跨批 | 固定 seed 跑很多次 ≠ 跨批，**必须换种子**；注入错误扫翻转点，证明判据在错的时候真的会红 |
| 收集数 | 测试全绿 ≠ 覆盖到了：路径/配置写错会让整批用例一条不跑而全绿 ⇒ 实测**用例收集数**，不能只看退出码 |
| 互证 | 至少两条**独立**实现互相对账并冻结残差。自实现 FK 验自实现 IK、残差必然很小，属自证 |
| 容差 | 按对象**登记** + 写明理由 + **未登记一律报错**。给"够大"的缺省 = 为通过而放宽阈值的开端 |

## 三、几何与物理真值的来源与边界

| 主题 | 结论 |
|---|---|
| 测量可复现 | ROI / 阈值 / 骨架模型必须跨 **≥2 批**验证；单批最优 = 过拟合 |
| 区间搜索 | 最优落在区间端点附近 ⇒ 那是区间人为截断，不是测量结果 |
| 参考实现 | 读 STEP / URDF 等复杂格式用**官方参考实现**；自研解析器的否定性结论必须先复核 |
| CAD 能反解什么 | 可由实体圆柱面反解**关节轴**；`length` 不可由 STEP 反推（STEP 姿态 ≠ 零点位）⇒ 只能实拍标尺 |
| 关节结构签名 | 两轴严格平行 ⇒ 平行四连杆的结构性签名，比经验拟合强 |
| 绝对角 / 局部角 | 耦合关节的合法域是"斜"的，轴对齐 `range` 无法表达；限位真值只在真值文件里 |
| 物理稳态 | 重力 + 有限 PD ⇒ 停在力矩平衡处；判据是"它在不在动"，不是"差多少" |
| 方向标定 | 改 `reverse` 会翻转"钳位端" ⇒ 所有越界用例的期望值要逐个重算（方向反了照样绿） |
| 已放弃路线 | CAD→模型直接接入、从 STEP 反推 `length`、自研 STEP/URDF 解析器、用 mesh bbox 当连杆长 |

## 四、诊断与修复顺序

1. 让两侧**同时打印**同一输入的结果（不靠读代码推演）。
2. 量偏差量级，判"常数 / 线性 / 系统性偏置 / 分支不同"。
3. 定位"引擎真正执行的那一份"。
4. grep 同类坑有无第二处。

**修法是转发，不是"再算一遍这次算对"**：第二处实现必须消失。
"为少 import 一个符号而自己重算"是错误经济学——多一条依赖可测可登记，多一份真值会腐烂。

改真值的连锁顺序：重生成产物 → 重冻结基线 → 重采黄金数据 → 修写死旧值的断言 → 同步文档。

## 反模式

- 改错字段而不消除第二处实现。
- 用 `--update` 让测试变绿。
- 用模型自声明的 id 反查选择器。
- 把"键集合相等"当模型一致的判据。
- 用欧拉角反解比对姿态（万向锁附近产出假失败）。
- 用"开机静态偏差"做自校准（快照取在松弛期，不可复现）。
- 物理稳态偏差去放宽全局阈值，或改物理模型凑判据。
- 把链路层"指令被送到并被接受"当成"物理到位"（无位置反馈时回读是开环目标值）。
